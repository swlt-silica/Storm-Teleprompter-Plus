# 云端稿库实施计划

## 用户已确认

京东云只保存稿件，各设备手动下载到本地后独立提词。只共享稿件，保留设备的字号、透明度、语音模型等设置。同一脚本编号重新上传时更新云端该稿；Markdown 格式由本项目定义，用户让 GPT 按该格式上传。

不复用现有的“远程提词从端”，不向服务器转发手机麦克风。完整备份仍为独立文件导入导出功能。

## 固定格式和接口

```md
---
script_id: "TC-001"
---

## 正文

大家好，这里是要朗读的台词。

## 备注

这一节不会进入提词正文。
```

标题等于脚本编号，编号保留前导零，允许字母、数字、点、下划线和连字符，最多 64 字符。正文是纯朗读文本，不放 Markdown 加粗、链接、列表、HTML 或代码标记；客户端以正文生成安全编辑器内容。

- `GET /healthz`：匿名健康状态。
- `GET /api/v1/library`：下载令牌或上传令牌读取稿库。
- `POST /api/v1/scripts/import-markdown`：上传令牌，UTF-8 Markdown，按编号幂等更新。
- HTTPS Bearer 令牌仅在请求头使用，不入 URL 或日志。设备不持有上传令牌。

## 部署

目标京东云 `117.72.205.55`，以独立低资源 systemd 服务运行，监听 `127.0.0.1:18431`，SQLite 持久化，不安装额外数据库。

复用既有 `note.swlt.work` 的 HTTPS，在 `/teleprompter/` 下新增精确独立反代；服务地址为 `https://note.swlt.work/teleprompter`。原有 Fast Note 路由保持；修改配置前保存有效回退副本，配置检查通过后平滑重载。通过请求头认证，不借用现有业务账号。

## 本地合并规则

云稿本地 ID 包含持久化 libraryId 和 scriptId，不根据标题覆盖其他本地稿件。重新下载时云端正文覆盖对应云稿的本地修改；保留已存在稿件的本地文件夹和独立提词设置，不删除云端缺席的稿件。同步前显示这条规则，不在活动提词页面执行。

## 待实机确认

HTTP 协议、服务端和本地导入可自动验证；用户手机安装后真实点击同步、离线提词和 Windows 实际运行仍需验收。不能将 Windows 编译成功当作已在用户 Windows 电脑运行通过。
